# 内容合规审稿表

用途：每条公开视频、图文、海报、私信模板发布前都要过一遍。尤其是 API、发票、电商投流、出海内容。

| 审稿项 | 判断标准 | 结果 | 修改记录 |
|---|---|---|---|
| ROI/GMV/排名/流量/爆单 | 出现即改写或删除 | 通过/修改/拒绝 |  |
| 官方、内部、最低价、不封号、无限量 | 出现即删除 | 通过/修改/拒绝 |  |

## 2. 高危词替换

| 高危表达 | 替代表达 |
|---|---|
| 半官方渠道 | 经授权/合规确认后再交付 |
| 内部渠道 | 企业服务通道 |
| 最低价 | 成本可控/预算可控 |
| 无限量 | 按合同约定预算池 |
| 不封号 | 按平台和上游规则合规使用 |
| 爆单 | 素材测试和复盘 |
| 保证 ROI | 不承诺 ROI，交付测试计划 |
| 共享 key | BYOK 或经授权企业接入 |
| 裸额度 | 用量托管服务 |

## 3. 发布前 5 问

```text
1. 有没有承诺效果？
2. 有没有暗示官方、内部、不限量或最低价？
3. 有没有引导站外私下交易？
4. 有没有暴露客户或上游敏感信息？
5. 有没有让客户误以为买的是裸额度，而不是服务？
```

任意一项为“是”，删掉重写。
