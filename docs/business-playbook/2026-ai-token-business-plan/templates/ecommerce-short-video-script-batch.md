# 电商短视频脚本批量表

用途：给抖店、小红书、TikTok Shop、Shopify 商品做可测试的短视频脚本。只交付脚本和测试建议，不承诺播放量、成交、ROI 或 GMV。

承接产品：2,999 短视频脚本包、3,999 投流素材测试陪跑、9,800 电商轻托管。

## 2. 每个 SKU 先做 5 个角度

```text
1. 痛点角度
2. 场景角度
3. 参数角度
4. 对比角度
5. FAQ 角度
```

## 3. 拍摄素材清单

| 素材 | 说明 |
|---|---|
| 商品实拍 | 正面、侧面、细节、包装 |
| 使用场景 | 桌面、通勤、收纳、宠物、厨房等 |
| 参数画面 | 尺寸、容量、材质、配件 |
| 前后对比 | 只能展示真实可验证变化 |
| 字幕条 | 不用夸大词 |
| 风险词列表 | best、guaranteed、永久、治愈、第一等 |

## 4. 录屏讲法

```text
短视频脚本别一次写 100 条。
先把 5 格填满：开头、场景、卖点、证据、行动。
能测试的脚本才有复盘价值。
```
