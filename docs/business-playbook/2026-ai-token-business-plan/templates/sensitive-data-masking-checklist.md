# 敏感数据脱敏检查表

用途：所有 API、客服、出海、电商内容在进入模型前，先确认是否包含敏感数据。公开视频只展示 demo 数据。

## 1. 脱敏字段

| 数据类型 | 示例 | 是否可直接进模型 | 处理方式 |
|---|---|---|---|
| 姓名 | 张三 | 否 | 替换为 customer_name |
| 手机号 | 13800000000 | 否 | 138****0000 或 phone_demo |
| 邮箱 | user@example.com | 否 | email_demo |
| 地址 | 上海市某小区 | 否 | city_level_demo |
| 订单号 | 202606140001 | 否 | order_demo_001 |
| 支付信息 | 卡号、支付流水 | 否 | 禁止上传 |
| 账号密码 | password、token | 否 | 禁止上传 |
| API key | sk-xxxx | 否 | 禁止上传，必须打码 |
| 聊天记录 | 客服对话 | 视情况 | 删除个人信息后可用 |
| 商品公开信息 | 商品名、规格、公开链接 | 可以 | 客户确认后使用 |
| 店铺规则 | 发货、退换、发票规则 | 可以 | 以客户提供为准 |
| 内部成本 | 采购价、供应商报价 | 谨慎 | 只在内部分析，不进公开内容 |
| 供应商信息 | 供应商姓名/电话 | 否 | 脱敏 |

## 2. API key 安全检查

```text
key 是否出现在前端代码：是/否
key 是否提交到代码仓库：是/否
key 是否发给无关人员：是/否
key 是否有预算上限：是/否
key 是否有请求日志：是/否
key 是否可轮换：是/否
key 泄露后是否有停用流程：是/否
```

## 3. 客户确认语

```text
请先确认：你发来的资料里是否包含姓名、电话、地址、订单号、邮箱、支付信息、账号密码或 API key。
如果包含，需要先脱敏。
我们只基于脱敏后的 demo/sample 数据做测试和内容生成。
```

## 4. 拒绝处理

```text
如果客户要求直接上传未脱敏订单、手机号、地址或支付信息，不接。
如果客户要求共享 key、绕平台限制或规避授权，不接。
如果客户要求用真实客户截图做公开视频，不接。
```
