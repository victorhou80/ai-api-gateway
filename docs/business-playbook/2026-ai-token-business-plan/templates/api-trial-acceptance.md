# 7 天 API 试跑验收表

用途：企业 API 试跑后判断是否能上线、是否要升级、是否要调整模型路由。不要只看“能不能返回一句话”。

承接产品：2,980 技术试跑、4,980 API 路由试跑、29,800 工作流包。

## 2. 错误分布

| 错误类型 | 次数 | 占比 | 可能原因 | 处理 |

| 403 | 0 | 0% | 权限不足 | 检查授权 |
