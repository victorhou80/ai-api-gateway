# Ecommerce Lead Qualification Template

Use this template for every ecommerce lead before recommending a package.

## Customer Basics

```text
客户姓名/微信：
公司/店铺名称：
平台：
类目：
店铺链接：
付款方式：个人 / 公司
是否需要发票：不需要 / 普票 / 专票
预计启动时间：
```

## Qualification Questions

```text
1. 现在有多少个 SKU？
2. 每月上新多少个 SKU？
3. 主要卡在哪个环节：标题卖点 / 详情页 / 客服话术 / 短视频脚本 / 直播脚本 / 投流素材？
4. 每天客服咨询大概多少条？
5. 内容现在由谁负责：老板 / 运营 / 客服 / 外包 / 代运营？
6. 是否有固定品牌调性或禁用词？
7. 是否需要公司付款、合同、普票或专票？
8. 是想先看样例，还是这周就要批量交付？
```

## Scoring

| Signal | Score |
|---|---:|
| 公司付款或要发票 | +3 |
| SKU 超过 30 | +2 |
| 每月上新超过 20 个 | +2 |
| 每天客服咨询超过 50 条 | +2 |
| 需要直播/短视频日更 | +2 |
| 有 2 人以上运营团队 | +2 |
| 愿意发商品资料 | +1 |
| 只问最低价，不愿给商品信息 | -3 |
| 要求虚假评价、刷单、夸大功效 | Reject |

## Recommendation

```text
总分：
推荐套餐：
推荐原因：
客户主要异议：
下一步动作：
下一步时间：
```

Score rules:

- 0-2: small sample or template pack
- 3-5: RMB 399 diagnosis or RMB 999 upstart package
- 6-8: RMB 1,999 / 2,999 task package
- 9-11: RMB 4,980 ecommerce standard trial
- 12+: RMB 9,800 monthly light managed package or RMB 29,800 growth package

## Quote Snippet

```text
按你现在的情况，不建议直接买大额度。
你更适合先用【套餐】解决【场景】。

本次交付包含：
1. 【SKU/脚本/话术数量】；
2. 【交付格式】；
3. 【修改轮次】；
4. 【服务周期】；
5. 【是否含发票】。

确认后我发付款和资料清单。
```

## Red Lines

Reject or escalate if:

- fake reviews
- fake orders
- false advertising
- prohibited product claims
- unlimited revision demand
- no product information but demands guaranteed conversion
- wants raw API key or shared account
