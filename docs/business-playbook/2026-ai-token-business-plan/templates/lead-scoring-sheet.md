# 线索评分表

用途：把“私信来了”变成可排序的销售线索。不要每个客户都花同样时间。

## 1. 评分表

| 维度 | 评分规则 | 得分 |
|---|---|---:|
| 客户身份 | 个人 0；小店/自由职业 +1；公司团队 +3；采购/财务/老板/技术负责人 +4 |  |
| 场景清晰度 | 只问价格 0；能说出场景 +2；有具体 SKU/API/团队流程 +4 |  |
| 预算信号 | 只要免费 -3；接受 39/99 +1；接受 399/999 +2；能讨论 2,980+ +4；明确 29,800+ +6 |  |
| 合同/发票 | 不需要 0；问普票 +2；问专票/合同 +4 |  |
| 使用规模 | 单人 0；2-5 人 +2；6 人以上 +4；多部门/多系统 +6 |  |
| API/出海复杂度 | 无 0；OpenAI-compatible +2；BYOK +3；生产系统/API 路由 +5 |  |
| 电商规模 | 1 个 SKU +1；30+ SKU +3；月上新 20+ +4；客服/投流/SEO 连续需求 +5 |  |
| 启动时间 | 随便看看 0；本月 +2；本周 +4；已排预算/等报价 +6 |  |
| 合规风险 | 要共享 key/绕平台/承诺 GMV/虚假宣传：直接拒绝或升级审查 |  |

## 2. 分数对应动作

| 分数 | 动作 |
|---:|---|
| 0-3 | 发公开资料或 demo，不重点跟进 |
| 4-7 | 推 39/99/199/399 低价任务或诊断 |
| 8-12 | 推 2,980/4,980 试用包 |
| 13-17 | 推 9,800 轻托管/出海模型包 |
| 18+ | 进入 29,800/98,000 正式报价池 |
| 红线命中 | 不报价，合规拒绝或升级审核 |

## 3. 三问分流

```text
1. 你主要做电商内容、API 接入、客服，还是团队用量？
2. 个人、小店，还是公司团队？
3. 需不需要合同、普票或专票？
```
