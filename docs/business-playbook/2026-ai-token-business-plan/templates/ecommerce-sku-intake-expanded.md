# 电商 SKU 资料收集表

用途：低价任务卡和电商内容包下单前必须先收资料，防止 AI 猜测，防止无限沟通。

承接产品：9.9 商品小样、39 单品快写、99 主推单品文案卡、199 小店上新、999 小店上新包、4,980 电商试用。

## 1. SKU 资料表

| 字段 | 填写说明 | 示例 |
|---|---|---|
| 客户名称 | 店铺或品牌简称 | Demo家居店 |
| 平台 | 淘宝/抖店/小红书店铺/TikTok Shop/Amazon/Shopify | 抖店 |
| 商品链接 | 没上架则填素材文件夹链接 | demo-link |
| SKU 编号 | 客户内部编号或自定义 | SKU001 |
| 商品名称 | 不要只写简称 | 便携防漏保温杯 |
| 类目 | 平台类目 | 家居日用/水杯 |
| 价格带 | 当前售价或预计售价 | RMB 59-99 |
| 目标人群 | 谁最可能买 | 上班族、学生、通勤人群 |
| 使用场景 | 具体到画面 | 通勤、办公室、上课、短途旅行 |
| 核心卖点 | 3-5 个事实型卖点 | 防漏、便携、容量大、易清洗 |
| 规格参数 | 尺寸、材质、容量、颜色等 | 500ml、304不锈钢、白/黑 |
| 差异点 | 与常见竞品相比的事实差异 | 杯盖结构、杯身更轻 |
| 已有素材 | 图片/视频/详情页/说明书/包装图 | 商品图 8 张、短视频 2 条 |
| 禁用词 | 客户或平台不能写的词 | 第一、最强、永久、治疗 |
| 必须出现信息 | 标题或详情必须写的内容 | 容量、材质、适用温度 |
| 售后/物流规则 | 以店铺规则为准 | 48 小时内发货，退换按平台规则 |
| 是否需要发票 | 低价任务通常默认不开，企业另议 | 否/普票/专票 |
| 客户确认人 | 最终确认资料的人 | 运营负责人 |
| 状态 | 待补资料/可生产/已交付/待确认 | 待补参数 |

## 2. 资料完整度检查

| 必填资料 | 是否已有 | 缺失影响 |
|---|---|---|
| 商品图 | 是/否 | 无法判断视觉卖点 |
| 商品链接 | 是/否 | 无法看现有标题和详情 |
| 基础参数 | 是/否 | 不能写尺寸、材质、容量 |
| 核心卖点 | 是/否 | 内容容易泛化 |
| 禁用词 | 是/否 | 容易踩平台或品牌风险 |
| 售后规则 | 是/否 | FAQ 不能准确回复 |
| 物流规则 | 是/否 | 不能写发货时效 |
| 授权素材 | 是/否 | 不能用于投放和公开内容 |

## 3. 低价任务卡边界

```text
39 单品快写：
- 1 个 SKU
- 标题 3 版
- 卖点 5 条
- FAQ 5 条
- 1 次轻修改
- 不电话沟通，不做投放，不承诺排名/GMV

99 主推单品文案卡：
- 1 个重点 SKU
- 标题 5 版
- 主图文案 3 版
- 详情页结构 1 版
- FAQ 10 条
- 短视频开头 3 条

199 小店上新：
- 3-5 个 SKU
- 每个 SKU 标题和卖点
- 不含详情页精修，不含投流，不含客服系统接入
```

