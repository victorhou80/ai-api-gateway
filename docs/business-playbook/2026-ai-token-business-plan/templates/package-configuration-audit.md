# 29,800 / 98,000 大包配置审查表

用途：报价前判断客户是否真的适合买 29,800 或 98,000，避免小客户被报大包，也避免大客户只买体验包导致交付不足。

## 1. 29,800 增长包配置审查

| 项目 | 标准配置 | 客户确认 |
|---|---|---|
| 价格 | RMB 29,800 |  |
| 服务期 | 30-60 天 |  |
| 适合客户 | 有持续 AI 使用的企业/电商/客服/内容团队 |  |
| 团队范围 | 1 个团队或约定使用人群 |  |
| 核心场景 | 1-2 个 |  |
| 用量池 | 按合同约定预算池，不是无限额度 |  |
| 预算预警 | 70% / 85% / 95% |  |
| 报表 | 每周 1 次用量简报 |  |
| 复盘 | 服务期内至少 1 次复盘 |  |
| 交付物 | 接入说明、预算表、用量表、复盘建议 |  |
| 支持 | 工作日基础支持 |  |
| 合同 | 支持 |  |
| 发票 | 普票/专票 |  |
| 客户需提供 | 场景、使用人、工具、是否 BYOK、发票信息 |  |
| 验收方式 | 交付清单 + 用量记录 + 复盘建议 |  |

不包含项：

```text
无限用量
共享 API key
广告预算
代运营
私有化部署
7x24 SLA
ROI/GMV/排名/爆单承诺
超出约定预算池的调用
未约定场景的新增开发需求
```

## 3. 升降级判断

| 客户情况 | 推荐 |
|---|---|
| 个人或只测试 1 个任务 | 9.9/39/399 |
| 小店 1-5 个 SKU | 39/99/199/999 |
| 公司团队但首次试跑 | 2,980/4,980 |
| 已有持续用量，需报表和发票 | 9,800/29,800 |
| 多人、多场景、持续调用 | 98,000 |
| 需要私有化、生产级 SLA、多系统集成 | 单独评估定制 |

## 4. 报价前必须问

```text
1. 几个人用？
2. 核心场景是什么？
3. 月预算大概多少？
4. 是否需要合同？
5. 普票还是专票？
6. 谁决策？
7. 谁验收？
8. 本月是否启动？
```
