# 企业 AI 采购比价表

用途：给老板、财务、采购看，不让客户只比“token 单价”。这张表适合录屏，也适合在私信里发 demo 版。

承接产品：399 诊断、2,980/4,980 试用包、9,800 企业试跑、29,800 增长包。

## 1. 比价总表

| 字段 | 供应商 A：官方直采 | 供应商 B：低价渠道 | 供应商 C：企业托管服务 |
|---|---|---|---|
| 采购方式 | 客户自行采购 | 渠道提供接入 | 服务商托管交付 |
| 适合客户 | 技术成熟、有财务流程 | 只看低价、能自担风险 | 需要合同、发票、报表和支持的团队 |
| 付款主体 | 客户公司 | 待确认 | 客户公司对服务商 |
| 开票支持 | 视官方主体而定 | 待确认 | 普票/专票，按实际服务确认 |
| 合同支持 | 视官方流程而定 | 待确认 | 支持正式合同 |
| 预算上限 | 客户自设 | 待确认 | 可设 70%/85%/95% 预警 |
| 用量报表 | 客户自拉 | 不一定有 | 日报/周报/月报按套餐 |
| API key 管理 | 客户自管 | 风险较高 | 按合同和权限管理，不公开展示 |
| 模型路由 | 客户自建 | 待确认 | 可按场景做路由和 fallback |
| 数据边界 | 客户自控 | 待确认 | 提供敏感数据脱敏清单 |
| 支持范围 | 官方文档/工单 | 待确认 | 工作日基础支持，复杂需求另议 |
| 不包含项 | 实施、报表、培训 | 待确认 | 无限用量、广告预算、代运营、ROI/GMV 承诺 |
| 验收方式 | 客户自定 | 待确认 | 试跑报告、用量记录、交付清单 |
| 总价口径 | 官方价格 | 渠道报价 | 套餐价 + 合同范围 |
| 推荐判断 | 适合成熟技术团队 | 风险较难核验 | 适合企业采购和持续使用 |

## 2. 采购前 7 问

```text
1. 谁在用：个人、运营、客服、技术，还是多个部门？
2. 用多少：日请求数、月预算、是否有上限？
3. 谁付款：个人报销还是公司付款？
4. 谁开票：普票、专票，付款主体和开票主体是否一致？
5. 谁维护：接口、限流、报错、续费、模型切换由谁负责？
6. 谁验收：业务负责人、技术负责人，还是财务/采购？
7. 出问题怎么办：是否有支持边界、响应时间和升级路径？
```

## 3. 录屏讲法

```text
企业采购 AI，不要只比单价。
你至少要比 7 件事：付款主体、合同、普票/专票、预算上限、用量报表、API key 管理和售后边界。
如果这些都没有，单价再低，长期也很难走公司账。
```
