# 19. Ecommerce Material Editing Toolkit And Workflows

## Core Clarification

This chapter is not about where to find photos.

Chapter 18 handles material sourcing and rights. This chapter handles:

- how to edit materials
- which tools to use
- how to batch-produce platform variants
- how to manage versions
- how to turn one product into multiple ads, posters, short videos, SEO content, and listing assets

Use this positioning:

> 素材服务不是找几张图，而是帮客户搭一套“商品素材处理、模板复用、批量导出、投放测试、复盘迭代”的工具链。

## Tool Stack By Customer Type

| Customer Type | Recommended Stack | Why |
|---|---|---|
| individual/small store | Canva / 稿定设计 / 创客贴 + 剪映/CapCut | low learning curve, templates, fast output |
| ecommerce operator | Canva/稿定 + Photoroom + 剪映/CapCut + Feishu/Notion sheet | product images, short videos, task tracking |
| cross-border store | Canva/Adobe Express + Photoroom + CapCut Commerce Pro + Sheets/Airtable | multilingual ads, product visuals, export variants |
| team with designer | Figma + Photoshop/Adobe Express + Premiere/CapCut + asset library | brand consistency, collaboration, versions |
| technical team | Figma templates + API/workflow automation + cloud storage + spreadsheet database | batch generation and system integration |

### 4. Batch And Template Production

Use for:

- 20 SKU title cards
- 50 product image variants
- 10 ad angle posters
- multi-platform resizing
- recurring monthly content

Possible workflows:

| Workflow | Tool Pattern |
|---|---|
| SKU poster batch | spreadsheet + Canva bulk/template or Figma component variants |
| product image cleanup | Photoroom batch/product editor + naming convention |
| short-video batch | CapCut templates + script table + product clips |
| cross-border listing variants | spreadsheet fields + AI copy + design template |
| ad hook testing | 5 angles x 3 hooks x 2 layouts = 30 variants |

Batch rule:

```text
先做模板，再批量替换；先做 3 个样例确认风格，再批量生产。
```

## Recommended Internal Workflow

### Step 1: Build A SKU Master Sheet

Every product should have:

```text
SKU
Product name
Platform
Category
Price
Target customer
Core benefit
Proof/supporting fact
Forbidden claims
Source material folder
Output status
Reviewer
Final link
```

### Step 2: Build Reusable Templates

Create templates for:

- product title card
- selling point card
- before/after problem-solution card
- short-video cover
- product FAQ card
- ad hook poster
- search/SEO keyword card
- cross-border listing card

### Step 3: Create Variant Rules

For each product, generate:

```text
3 title angles
3 selling-point angles
3 short-video hooks
2 poster layouts
2 thumbnail styles
1 FAQ card
```

This gives enough testing material without overwhelming the customer.

### Step 4: Export Platform Variants

Common export ratios:

| Ratio | Use |
|---|---|
| 1:1 | product cards, marketplaces, square social posts |
| 4:5 | Xiaohongshu/Instagram feed style |
| 9:16 | Douyin/TikTok/Reels/Shorts |
| 16:9 | YouTube, website, presentation |
| platform-specific | Amazon/Shopify/TikTok Shop marketplace rules |

Always confirm the latest platform-specific requirements before final delivery.

### Step 5: Archive And Name Files

Use:

```text
customer_platform_sku_assettype_angle_ratio_date_v1
```

Examples:

```text
ABCShop_TikTokShop_WaterBottle_poster_coldproof_9x16_2026-06-13_v1.png
ABCShop_Amazon_Headphones_listing_mainimage_1x1_2026-06-13_v2.jpg
ABCShop_Shopify_Backpack_video_hook01_9x16_2026-06-13_v1.mp4
```

### Step 6: Review Before Delivery

Review:

- spelling
- price
- discount
- product facts
- forbidden claims
- platform-sensitive words
- logo/trademark use
- image rights
- ratio and export quality
- whether AI-generated elements need disclosure or review

## Tool Usage Boundaries

Do not:

- remove watermarks from unlicensed materials
- use templates/assets outside license scope
- use music without checking license
- use AI-generated people/brand/celebrity endorsements misleadingly
- copy competitor layouts too closely
- export platform-forbidden claims
- promise ad approval or conversion

Do:

- keep license proof
- keep original material
- keep editable source file
- export final assets separately
- label version numbers
- keep customer approval record
