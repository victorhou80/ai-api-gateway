# 06. 30/60/90 Day Roadmap

## Days 1-15: Go/No-Go Due Diligence

Goal: determine whether quota-based service can be sold at all.

Tasks:

- request upstream authorization chain
- verify discount source and quota type
- review upstream terms for resale/API integration
- confirm data-processing terms
- confirm invoice/cost proof
- ask platform service/category support whether the service can be listed
- consult legal/tax professionals on service structure
- build unit-economics model including tax, fees, refunds, support, and acquisition

Decision:

- If written authorization is clear: continue B2B usage-management pilot.
- If unclear: stop quota route and sell implementation/consulting/BYOK service.

## Days 16-30: Build Operating Base

Tasks:

- register/confirm business entity and scope
- open company collection path
- build quote template
- build service agreement
- build refund policy
- build ordinary/special invoice information form
- confirm invoice item wording with accountant
- define red-invoice/refund handling process
- build acceptable-use policy
- build data restriction list
- create CRM fields
- create 4 B2B packages
- launch enterprise/professional accounts
- publish first 50 content pieces
- run first 20-30 customer interviews

Target:

- 50 valid leads
- 10 quotes
- 3-5 paying customers
- RMB 50,000-100,000 GMV

## Days 31-45: Small B2B Pilot

Do not public-scale yet.

Pilot customers:

- ecommerce content teams
- customer-service teams
- training/education internal systems
- AI tool studios
- SaaS teams with existing model spend

Tasks:

- sign contract/order
- collect prepayment
- activate isolated customer workspace or access
- generate weekly usage report
- track support time
- track actual gross margin
- record customer objections
- build anonymized case studies

Target:

- 10-20 paid customers
- at least 5 case assets
- clear renewal triggers
- no major support/compliance incident

## Days 46-60: Platform Launch

Tasks:

- launch official lead form
- launch shop diagnostic service
- run 3-5 weekly live sessions
- publish 3 Xiaohongshu notes/day
- publish 2 Douyin videos/day
- test 3 customer segments
- test 5 topic hooks
- test 3 lead-form titles
- classify leads A/B/C/D

Target:

- 300-600 valid leads
- 30-60 A-grade leads
- 20-30 diagnostics
- RMB 250,000-400,000 monthly GMV

## Days 61-90: Controlled Scale

Tasks:

- double down on top 3 content themes
- add one vertical account if conversion is proven
- build channel partners: AI training, dev shops, SaaS consultants, ecommerce agencies
- formalize weekly usage report
- formalize renewal alerts
- implement risk thresholds
- prepare 10 anonymized cases
- create Q4 enterprise package push

Target:

- monthly GMV RMB 350,000-500,000
- renewal rate 60%+
- A-grade lead close rate 15%-25%
- 20-40 enterprise customers in pipeline

| KPI | Target |
|---|---:|
| weekly GMV | RMB 220,000-300,000 after ramp |
| weekly gross profit | at least 35% after usage cost, before tax and overhead |
| quote pipeline | 3x weekly GMV target |
| valid leads | 80-150 |
| A-grade leads | 20-40 |
| refund rate | below 3% |
| support tickets | below 3 per RMB 10,000 GMV |

## Team Setup

Minimum team:

| Role | Responsibility |
|---|---|
| founder / lead salesperson | diagnosis, large deals, negotiation, payment |
| content operator | Xiaohongshu/Douyin content, comments, live clips |
| SDR/customer service | message handling, booking, CRM updates |
| technical support | activation, reports, troubleshooting, renewal alerts |
| part-time finance | contracts, payment confirmation, invoices, margin ledger |

Compensation:

- sales commission based on gross profit, not GMV
- SDR reward based on qualified diagnoses and closed deals
- renewal commission lower than new-sale commission
- discount approval required below margin floor
