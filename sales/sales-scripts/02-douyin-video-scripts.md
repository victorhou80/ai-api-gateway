# 抖音短视频脚本

## 脚本 1：电商客户痛点

镜头 1：电脑屏幕，展示商品表格。

口播：

```text
你做电商，如果每天要写几十上百个商品标题、五点描述和 SEO 关键词，其实很适合接 AI API。
```

镜头 2：展示 API 调用生成结果。

口播：

```text
但很多团队卡在这里：不会接 API，不知道用量怎么算，也不知道月底怎么给老板对账。
```

镜头 3：展示用量看板。

口播：

```text
所以我们做的是 API 接入托管，不只是给你一个 Key。
你可以看到每天请求了多少次、用了多少 Token、哪个模型最花钱。
```

镜头 4：展示套餐。

口播：

```text
现在有 1 天试用包，适合先跑真实商品数据。正式客户可以签合同、开发票、出月度用量表。
```

结尾字幕：

```text
适合电商 / 出海团队 / 开发者
私信：API 试用
```

## 脚本 2：程序员接入

口播：

```text
如果你的系统支持 OpenAI 标准 API，那接入其实很简单。

你只需要换三个东西：
第一，Base URL。
第二，API Key。
第三，模型名。

后面请求量、Token、模型分布、成本，都可以在用量看板里查。

适合 Dify、Coze、自研系统、内部工具、AI 应用团队。
```

屏幕展示：

```python
client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.example.com/v1"
)
```

结尾：

```text
需要测试 Key，可以先开 1 天试用。
```
