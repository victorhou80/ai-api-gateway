# 04. 销售打法和线索推进 SOP

## 目标客户分类

| 客户类型 | 需求 | 推荐产品 |
|---|---|---|
| 出海电商 | 标题、五点描述、SEO、多语言、客服 | 9.9 试用包 -> 99/399 电商包 |
| 国内电商 | 批量文案、直播脚本、客服回复 | 9.9 试用包 -> 99 电商轻量包 |
| 程序员 | API 接入、Dify、Coze、自研工具 | 499 开发者包 |
| AI 工具团队 | 需要稳定模型网关和用量表 | 企业启动包 |
| 企业客户 | 合同、发票、预算控制、多人使用 | 9800/98000 企业包 |

## 销售核心话术

主线不要讲“便宜 token”，讲：

```text
我们提供一套 AI API 接入托管服务，客户可以用标准 OpenAI/Claude 接口接入，
同时有用量看板、预算控制、月度报表、合同发票和技术支持。
```

## 客户推进阶段

### 阶段 1：获客

目标：让客户知道你们能解决“AI 接入 + 用量管理”的问题。

渠道：

1. 小红书：电商 AI、省钱工具、出海运营、商品文案。
2. 抖音：场景演示、屏幕录制、前后对比。
3. 微信群：开发者群、电商群、跨境群。
4. 知乎/SEO：OpenAI API 接入、Claude API 替代、Dify 模型接入。
5. 私域朋友圈：案例和用量看板截图。

### 阶段 2：试用

目标：让客户买 9.9 或申请 1 天试用。

给客户：

```text
1. API Key
2. API Base URL
3. 用量看板地址
4. 3 个示例 prompt
5. 接入说明
6. 技术支持微信
```

### 阶段 3：转正

触发条件：

1. 客户试用超过 30 分钟。
2. 客户跑了真实业务数据。
3. 客户问价格、稳定性、发票、合同。
4. 客户要求更多额度或更长有效期。

转正话术：

```text
你这边已经跑出真实用量了，我建议不要继续用试用 Key。
正式包可以给你单独建生产 Key，额度、并发、用量看板都会稳定一些。
后续每月也能给你出用量表，方便公司内部报销或核算成本。
```

### 阶段 4：企业升级

触发条件：

1. 客户有多人使用。
2. 客户需要开票。
3. 客户要接到内部系统。
4. 客户关心预算控制。
5. 客户要求月报、合同、稳定性。

升级话术：

```text
如果你们是团队长期用，我建议走企业包。
企业包不是单纯加额度，而是会给你们做独立 Key、预算上限、月度用量表、接入支持，
合同和普票/专票也都可以配合。
```

## 销售禁区

不要说：

```text
官方内部渠道
保证不封
无限量
比官方便宜多少多少
绕过限制
保证爆单
保证 ROI
```

可以说：

```text
我们做的是 AI API 接入托管。
可以提供用量看板。
可以按预算控制。
可以提供技术接入。
可以签合同和开发票。
```
