# 06. 用量表、毛利表和提成表

## 三类表

必须把报表分成三类：

| 报表 | 给谁看 | 目的 |
|---|---|---|
| 客户用量表 | 客户 | 对账、报销、确认消耗 |
| 内部毛利表 | 老板/运营 | 看收入、成本、利润 |
| 销售提成表 | 销售/财务 | 算提成、复盘续费 |

## 客户用量表字段

| 字段 | 说明 |
|---|---|
| 账期 | 例如 2026-06-01 至 2026-06-30 |
| 客户名称 | 企业名或联系人 |
| 套餐名称 | 电商轻量包/企业包 |
| API Key 片段 | 只显示 `sk-xxx...abcd` |
| 日期 | 按天汇总 |
| 场景 | 商品标题/SEO/客服/开发测试 |
| 模型 | 模型名 |
| Endpoint | `/v1/chat/completions` 等 |
| 请求数 | 总请求数 |
| 成功数 | 成功请求 |
| 失败数 | 失败请求 |
| 输入 Token | input/prompt tokens |
| 输出 Token | output/completion tokens |
| 缓存 Token | cache tokens |
| 总 Token | 汇总口径 |
| 消耗额度 | 客户可理解的美元或人民币额度 |
| 平均耗时 | duration |
| 备注 | 异常说明 |

## 内部毛利表字段

| 字段 | 说明 |
|---|---|
| 客户 | 客户名称 |
| 销售 | 归属销售 |
| 套餐 | 产品包 |
| 回款金额 | 客户实际付款 |
| 开票金额 | 发票金额 |
| 标称额度 | 对客户承诺的额度 |
| 实际消耗 | 系统记录的消耗 |
| 实际成本 | 按 3 折成本折算 |
| 毛利 | 回款金额 - 实际成本 - 其他成本 |
| 毛利率 | 毛利 / 回款金额 |
| 提成前利润 | 毛利 |
| 提成后利润 | 毛利 - 销售提成 |
| 备注 | 退款、赠送、异常 |

## 销售提成表字段

| 字段 | 说明 |
|---|---|
| 客户 | 客户名称 |
| 销售 | 销售姓名 |
| 产品 | 套餐 |
| 回款日期 | 实收日期 |
| 回款金额 | 实收金额 |
| 退款金额 | 如有 |
| 净回款 | 回款 - 退款 |
| 毛利 | 内部毛利 |
| 提成比例 | 10%-15% |
| 应发提成 | 按规则计算 |
| 发放状态 | 未发/已发 |

## 场景标签建议

为了让电商客户看懂用量表，建议通过 Key 名称或 usage label 做业务场景区分：

```text
ecom-title      商品标题
ecom-bullet     五点描述
ecom-seo        SEO 关键词
ecom-translate  翻译本地化
ecom-cs         客服回复
dev-test        开发测试
prod-api        生产接口
```

## 报表生成流程

第一版可以人工：

```text
sub2api admin usage
  -> 导出/复制数据
  -> 汇总到 Excel
  -> 生成客户月报
  -> 内部计算毛利
  -> 销售复盘续费
```

第二版可以半自动：

```text
定时任务查询 usage_logs
  -> 按客户/Key/模型/日期聚合
  -> 生成 xlsx
  -> 生成 PDF
  -> 邮件/企业微信发送
```

## 每周复盘问题

1. 哪些客户用量最高。
2. 哪些客户消耗异常。
3. 哪些模型成本过高。
4. 哪些试用客户有转正机会。
5. 哪些客户需要降级或升级套餐。
6. 哪些销售话术带来的客户质量最好。
7. 是否有客户接入失败或长时间不用。
