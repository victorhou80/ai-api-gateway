# 证据与来源

## 证据等级

| 等级 | 定义 | 可以支持什么 | 不能支持什么 |
|---|---|---|---|
| A | 模型厂商官方价格/条款 | 官方牌价、服务层级、计费字段 | 第三方站点实际使用了该上游 |
| B | 中转站第一方价格页 | 该站在某时点公开了某报价和声明 | 模型真实、来源合法、长期可用 |
| C | 第三方价格抓取与监测 | 市场横截面、近期请求成功率 | 支付来源、模型真伪、未来 SLA |
| D | 分析文章、站方标签、社区经验 | 风险假设和待验证线索 | 犯罪事实或合规结论 |

## 本次来源

### A 级：官方基准

1. [OpenAI API Pricing](https://developers.openai.com/api/docs/pricing)

   用途：GPT 标准、Batch/Flex、缓存与工具价格锚点。价格随时可能变化。

### B 级：站方第一方页面

2. [OneHop Pricing](https://onehop.ai/zh-Hans/pricing)

   用途：GPT-5.6/5.4 等公开输入、输出价格，人民币固定 6.8 展示汇率，充值活动。页面横幅与表格存在 5%/10% 冲突，因此以逐项价格表为准。

3. [随想模型与价格](https://sui-xiang.com/models)

   用途：公开官方基准价和“最终扣费乘模型倍率”的说明。购买页需要登录，因此未取得实时 GPT 倍率。

4. [RTOC 模型价格页](https://ai.rtoc.cc/pricing)

   用途：公开 GPT 0.06、GPT Pro 0.20 资源组和部分逐模型价格。

### C 级：第三方价格与监测

5. [PriceAI API 中转站价格榜](https://priceai.cc/api-transit)

   用途：站点级充值倍率、模型倍率、来源标签和近期可用性样本。

6. [PriceAI 中转 API 模型对比](https://priceai.cc/api-transit/models)

   用途：GPT-5.6 Sol 等具体模型的跨站价格分布。

7. [PriceAI API 中转指南](https://priceai.cc/guides/api-transit)

   用途：充值系数、模型倍率、来源标签和榜单权重定义。

### D 级：风险假设与行业分析

8. [API Ranking：AI API 中转站为什么能这么便宜](https://apiranking.com/guides/why-relay-so-cheap)

   用途：低价来源分类、推荐与特价通道差异、模型替换与隐性计费假设。属于第三方分析，相关数字未视为审计事实。

## 引用规则

- 价格必须带抓取日期和模型全名；
- 站方声明使用“声称”“公开显示”等措辞；
- 第三方来源标签不得改写为已验证事实；
- “低价”“逆向”“号池”不能自动推导出“盗刷”；
- 对违法来源的认定必须引用支付、账户归属、平台调查或司法证据；
- 市场页面可能含推广、赞助或联盟关系，本文不把榜单排序当作信誉认证。
