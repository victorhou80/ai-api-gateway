# AI API 中转站价格与风险研究

> 研究快照：2026-07-23（Asia/Shanghai）
> 核心口径：用户买到“官方标准 API 牌价 1 美元的 Token 用量”需要支付多少人民币。

本仓库整理国内 AI API 中转市场的公开价格、Token 购买力、线路来源与风险边界，重点比较 GPT / ChatGPT 模型 API。它不是中转站推荐榜，也不提供黑号、盗刷、逆向或绕过上游风控的方法。

## 一句话结论

公开市场不是单一商品，而是至少混合了正式 API、云厂商、订阅账号池、IDE 配额、逆向协议、活动赠金、二级分销和未披露上游。2026-07-23 的公开报价中，GPT-5.6 Sol 同名线路从约 `C=0.03` 到 `C=1.00` 都存在；价格相差 33 倍，不代表交付物、合法性、稳定性和隐私水平相同。

其中：

- `C=1.00`：人民币 1 元买官方牌价 1 美元的用量；这是本项目的自有定价基准。
- `C=0.68`：OneHop 当前 GPT 常规公开价；每元约有官方 `$1.4706` 的购买力。
- `C=0.30`：每元约有官方 `$3.3333` 的购买力，属于必须解释上游成本来源的低价区间。
- `C=0.03–0.10`：公开市场确有报价，但普通官方按量 API 直采无法解释这一售价；公开标签多见混池、Plus/Pro、逆向、号池或未披露。

**极低价是风险信号，不是盗刷的充分证据。** 盗刷信用卡、被盗 Key 或被接管账号只是可能来源之一；订阅切片、IDE 内部额度、赠金、模型替换、虚增 Token 和短期补贴同样可能造成低价。没有支付争议、上游账单、封禁原因或司法证据，不应公开断言某个经营者“盗刷”。

## 统一价格尺子

定义：

```text
C = 用户买到官方标准牌价 $1 的 Token 用量所支付的人民币

每 1 元的官方美元购买力 = 1 / C
相对 C=1 基准的 Token 倍数 = 1 / C
```

| 市场档位 | C（元/官方 $1 用量） | 1 元获得的官方牌价购买力 | 相对 C=1 的 Token 数 | 风险解释 |
|---|---:|---:|---:|---|
| 极端福利/混池 | 0.03–0.10 | $10–$33.33 | 10–33.33 倍 | 普通官方 API 直采无法解释；需验证模型、来源和扣量 |
| 低价订阅池 | 0.10–0.20 | $5–$10 | 5–10 倍 | 常见 Plus/Pro/IDE/号池/逆向标签 |
| 中档号池 | 0.20–0.45 | $2.22–$5 | 2.22–5 倍 | 0.30 位于此档；不必然盗刷，但必须解释来源 |
| 稳定/高级池 | 0.45–0.80 | $1.25–$2.22 | 1.25–2.22 倍 | 可能强调 Team/Pro、缓存和稳定性；仍需证据 |
| 透明人民币本位 | 0.80–1.20 | $0.83–$1.25 | 0.83–1.25 倍 | 易解释、适合做可信生产线路 |
| 官方标准 API 现金直购 | 约 7.0–7.3 | $0.14 左右 | 约 0.14 倍 | 按美元汇率直接支付的成本锚点 |

## 公开市场观察

本次快照记录到的 GPT-5.6 Sol 公开路线包括：

- `0.03–0.085`：混池、Plus、福利组、Codex-plus、上游未披露等；
- `0.10–0.20`：Pro/Plus/混池/福利资源组；
- `0.28–0.45`：Codex Pro、Team/Plus 标准或稳定通道；
- `0.68`：OneHop Official 公开价格；
- `1.00`：普通人民币本位价或其他特殊分组。

第三方价格榜可以证明“某时点公开了这些报价”和“监测请求曾经成功”，但不能证明：

- 返回的一定是标称模型；
- 支付来源合法；
- 账号或额度归中转站合法所有；
- 明天仍可用；
- 隐私、数据驻留和服务条款合规；
- 失败请求、缓存和 reasoning tokens 计费正确。

## 商业判断

如果产品当前定价是 `C=1.00`，不要与 `C=0.03–0.30` 的线路只打 Token 单价战。更可持续的定位是“可信生产线路”：

- 上游来源可解释、可审计；
- 标称模型不替换；
- 输入、缓存、输出、reasoning 用量逐请求可核对；
- 失败请求扣费政策清楚；
- Prompt、代码和文件的数据处理边界明确；
- 有主体、合同、发票、退款和余额保护；
- 有可测量的 SLA、限流和故障切换策略；
- 高风险实验线路与生产线路彻底隔离。

建议把定价与风险分层，而不是把来源不清的号池混进正式产品：

| 产品层 | 建议 C | 用途 |
|---|---:|---|
| 可信生产线 | 0.80–1.00 | 默认，强调证据、账单、隐私与 SLA |
| 合规经济线 | 0.68–0.80 | 仅在真实上游成本和服务条件可证明时提供 |
| 首充/限时额度 | 可短期低于 0.68 | 明确额度、模型、期限和不可提现规则 |
| 实验线路 | 不以低价承诺长期供应 | 与生产线隔离，不承载敏感数据和关键业务 |

## 使用计算器

无需第三方依赖：

```powershell
python scripts/price_calculator.py --c 0.30 --input-price 5 --output-price 30 --input-share 0.9
```

输出包括：

- 每元官方牌价购买力；
- 每元输入 Token；
- 每元输出 Token；
- 给定输入/输出比例下的总 Token；
- 与 `C=1.00` 和 `C=0.68` 的相对倍数。
