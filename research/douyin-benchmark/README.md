# 抖音获客对标研究：江胖子（高客单 IP 精准获客）

本目录保存公开页面观察和少量本地视频媒体分析，用于设计 AI API 网关/token 云转接业务的内容营销方法。研究对象主页登录后显示 40 条作品；页面观察在已登录浏览器中完成，但未导出或保存 Cookie、密码、设备指纹、签名参数。

## 目录内容

- `coverage_report.md`：40 条作品覆盖状态、主题簇和安全边界。
- `visible_works_40.md`：40 个公开作品 ID 清单。
- `summary_methodology.md`：方法论、逐条页面摘要与迁移建议。
- `promotional_scripts.md`：面向 AI API 网关业务的合规宣传脚本。
- `frames/`：5 条已取得视频的关键帧接触表（非原视频）。
- `metadata/`：5 条视频的分辨率、帧率、时长和帧数元数据。

## 证据等级

- A：本地视频逐帧扫描和媒体元数据。
- B：登录后公开作品页的标题、互动和章节要点（页面机器摘要，不是逐字稿）。
- C：基于公开信息的归纳和业务迁移建议。

不要将 B/C 级内容表述为完整逐字稿、全量视频下载或作者本人授权。当前覆盖口径为：40/40 条作品完成登录后页面观察；公开接口样本为 21 条且曾返回 `has_more=1`；5 条视频完成本地约 30fps 媒体核验。商业发布前应重新核验第三方内容版权、平台规则和上游模型授权。
