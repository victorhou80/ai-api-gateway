## 2. 可复用的获客漏斗

`反常识标题` → `点名同行/老板的错误` → `给错误命名（如“痛点翻译法”“投产游戏”）` → `白板演示一个因果链/公式` → `把抽象观点落到钱、客户、成交` → `暗示完整体系在主页/后续内容` → `关注/评论/私信承接`

### 每一层的作用

1. **反常识标题**：用“80%”“最容易犯的错”“为什么敢亏钱”等数字或冲突制造点击理由。
2. **身份对立**：反复使用“你的同行”“老板”，让目标客户感觉被直接点名。
3. **概念命名**：把普通经验包装成可记忆的专有词，形成作者资产。
4. **可视化推理**：白板上的箭头、比例、账本让观点看起来可验证，降低纯口播的不信任。
5. **商业结果**：把内容从“涨粉技巧”拉回“客户、利润、成交”，筛掉低意向泛流量。
6. **系列化**：以“第4笔账/第5笔账”“完整8笔账”等编号制造追更和主页浏览。

### 浏览器公开章节摘要补充

登录后直接打开作品页，抖音页面提供了机器生成的“章节要点”。已核验的两个补充样本：

- **7679090876166195048《流量越大，越挣钱？》**（1:50）：章节为“有效流量公式→无效流量影响→流量净价值公式→个人经验”。核心公式是 `有效流量=总流量×目标客户占比`、`流量净价值=有效客户价值-筛选成本`。
- **7648198627927708315《超级购买理由》**（4:28）：章节为“避免只说卖点→回答为什么选你/为什么现在买→三个硬核指标→商业逻辑→提问找购买理由→公式落地”。该条页面互动约 8702 赞、912 评论、8679 收藏、5059 分享，说明“可执行框架＋收藏价值”比单纯观点更容易沉淀。
- **7652035354790530395《4类炫耀资产》**：判断资产、结果资产、阅历资产、认知资产；页面给出的数量化动作是 5/10/15/20 条，最终目标是用资产信号筛选客户。
- **7652571210483980006《获客母版视频》**：案例→五个人性开关（恐惧、防御、贪婪、从众、幻想）→三步公式（卖点翻译买点→对应开关→交给 AI）。
- **7656424437466291955《为什么越拍越廉价》**：以“柠檬市场”解释价格战，再用信号传递、独家经历、真实案例、行业标准和做事标准构成不可模仿信号。
- **7655660369834508390《脑白金旧信念》**：挖掘用户旧信念→翻译产品与信念的关系→植入信念与 IP，核心是降低教育市场成本。

这些摘要来自已登录浏览器的可见页面，不等同于原始逐字稿；逐帧级结论仍以本地下载视频为准。部分页面摘要可能因加载状态变化而缺失，缺失项不做推断。

### A. 7630537759313356786《怎么让客户刷到你》

- Hook（0–3s）：封面“成交时刻/0粉3天获客？”先给结果冲突。
- 观点：不是追求曝光，而是让刷到的人在正确时刻付费。
- 论证：通过白板把“触达→信任→支付”串成一套方法。
- 优点：结果导向强，用户收益明确。
- 问题：4 分钟以上，若中段没有真实案例，留存可能下降；“0粉3天”容易被理解为承诺。
- 优化：加入可核验的时间范围、行业前提和失败条件，避免绝对化表达。

### B. 7631919957631253870《同行最容易犯的错》

- Hook：封面“痛点翻译法，3步把焦虑变成交”。
- 观点：越直接喊痛点，用户越反感；应把痛点翻译成购买理由。
- 论证：白板分步演示“表面焦虑→真实损失→可执行选择”。
- 优点：有自造术语，容易形成记忆点。
- 问题：术语若不在 10 秒内给出例子，会显得玄学。
- 优化：第 1 个例子用具体行业、金额和前后文案对比。

### C. 7640548791624138222《80%老板做短视频都是在自毁信任》

- Hook：数字+强判断，随后反转“不做网红，做生意”。
- 观点：过度表演会消耗信任，内容应服务成交资产。
- 论证：用白板解释“自嗨内容→低质量线索→信任损耗”。
- 优点：人设鲜明，价值取舍清楚。
- 问题：80% 属于经验性数字，缺少来源；容易触发质疑。
- 优化：改成“我观察到的大多数客户”，并展示匿名样本。

### D. 7678431528800997492《为什么敢亏钱买客户》

- Hook：同行为什么敢亏钱买客户？
- 观点：利润不是一单赚多少，而是客户长期价值/复利。
- 论证：把一次投放拆成客户价值、复购和后续转介绍。
- 优点：把“亏钱”重新定义为投资，击中经营者决策。
- 问题：若只讲概念，用户仍不知道如何算自己的数。
- 优化：给出 3 个可代入的数字模板和盈亏平衡公式。

### E. 7678687415268134031《短视频变现概率》

- Hook：封面“变现概率/爆一次靠概率，持续赚钱才是能力”。
- 观点：一次爆款不等于稳定生意，必须管理投产概率。
- 论证：白板写出投入、产出、成功率和持续现金流的关系。
- 优点：系列编号“第5笔账”强化追更。
- 问题：概率口径不明；缺少实际区间和样本量。
- 优化：展示匿名化的 30 条内容数据，标注计算口径。

## 4. 对我们 token 云转接业务的迁移

### 应保留

- 结果语言：从“模型参数”翻译为“响应速度、成功率、可预测账单”。
- 反常识切口：例如“便宜 token 不一定省钱，失败重试才是隐形成本”。
- 白板公式：`有效请求成本 = token 费 + 失败重试 + 延迟导致的人工成本`。
- 系列化：第 1 账（稳定性）、第 2 账（成本）、第 3 账（合规）、第 4 账（迁移）。
- 具体筛选：点名 SaaS 团队、独立开发者、工作室，而非泛泛“所有人”。

### 必须改写

- 不承诺“无限额度、永久免费、绕过地区限制、100% 稳定”。
- 不宣传共享 ChatGPT 账号、买卖 API Key、盗用 Cookie、规避平台风控。
- 明确上游授权、可接受用途、数据留存和退款规则。
- 价格用“示例账单/区间”而非虚构收益；让客户能复算。

## 5. 拍摄执行模板（60–90 秒）

1. 0–2s：大字冲突句 + 人物入画。
2. 2–8s：点名具体客户和一个高频错误。
3. 8–20s：给错误起一个短名字，并展示失败后果。
4. 20–55s：白板写 3 步或 1 个公式，至少一个真实数字示例。
5. 55–75s：展示控制台/账单的脱敏截图，说明适用边界。
6. 75–90s：CTA：评论关键词领取计算表/试用额度；私信前先阅读服务条款。

## 6. 关键指标

- 3 秒留存、25% 播放完成率、评论中目标客户占比；
- 试用→付费转化、首日成功率、P95 延迟、退款/拒付率；
- 负面反馈中“承诺不实/价格不透明/数据安全”的比例。
